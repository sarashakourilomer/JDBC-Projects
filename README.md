# JDBC-Projects
Java projects using JDBC to connect and interact with PostgreSQL databases.

## Projects

- **Banking System** — Banking application connected to PostgreSQL using JDBC.
- **Library Management System** — Library management application connected to PostgreSQL using JDBC.
- **Exam Booking Management System** — Exam booking application connected to PostgreSQL using JDBC.

## Technologies

- Java
- JDBC
- PostgreSQL
- Maven
- Git & GitHub
